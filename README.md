# Relaxer

Terminal CLI for enjoying my spare time.

- Reading .txt books in terminal.
- More ...

```
Usage: relaxer [options] [command]

Options:
  -V, --version             output the version number
  -h, --help                display help for command

Commands:
  book <userInputBookPath>  Reading a book in terminal.
  help [command]            display help for command
```

## Book mode

```
Command guide in reading a book:
  - Start a command with ':'
  - 's <string>' to search a string in the book
  - 'g <number>' to go to specific line number
```
